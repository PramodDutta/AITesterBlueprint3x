Quick demo

import math

print(math.pi)                # 3.141592653589793
print(math.sqrt(144))         # 12.0
print(math.ceil(4.1))         # 5
print(math.floor(4.9))        # 4
print(math.factorial(5))      # 120
print(math.gcd(12, 18))       # 6
print(math.lcm(4, 6))         # 12
print(math.pow(2, 10))        # 1024.0
print(math.log(100, 10))      # 2.0
print(math.degrees(math.pi))  # 180.0
print(math.hypot(3, 4))       # 5.0
print(math.dist([0,0], [3,4]))# 5.0
print(math.isclose(0.1+0.2, 0.3))  # True
print(math.comb(5, 2))        # 10
print(math.perm(5, 2))        # 20
print(math.trunc(-4.7))       # -4
print(math.fsum([0.1]*10))    # 1.0  (sum() gives 0.9999999999999999)

Gotchas

  • math.pow() always returns float; builtin pow() keeps int and supports a 3rd modulus arg.
  • Trig takes radians, not degrees. Convert with math.radians().
  • math.sqrt(-1) raises ValueError. Use cmath.sqrt(-1) for complex.
  • math.nan != math.nan. Test with math.isnan().
  • For float lists, prefer fsum() over sum() when precision matters.
